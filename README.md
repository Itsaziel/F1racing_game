# 🏁 F1-Style Racing Game 🏎️💨
A fast-paced, competitive racing game inspired by Formula 1, featuring multiplayer, AI opponents, and dynamic track effects!

# 🚀 Features:
* 🏎 Realistic Racing Mechanics
DRS (Drag Reduction System) – Just like real F1, activate DRS for a speed boost on straights!

* 5-Lap Races – Compete in quick, intense races with a focus on strategy and speed.

* Particles & Sparks – Visual effects when cars scrape the track or collide for added immersion.

* 🤖 AI Opponents (NEAT Algorithm)
NEAT-Python trained AI – Not perfect, but learning! Watch as AI drivers take different racing lines and make mistakes.

* 🌐 Multiplayer (Party Code System)
Create or Join Games – Host a race with a 4-digit party code or enter a friend’s code to join.

* Internet-Based – Play with anyone online.

* 🎵 Sound & Design
* Background Music – Energetic soundtrack to keep the adrenaline pumping.

* 2 Unique Car Designs – Choose between different vehicle styles.
